## Top 10 Blocking Issues

### 1. 🔴 **CRITICAL: Login Column Name Mismatch**
**File:** `apps/app/server/routes.ts:3235`  
**Issue:** Code tries to access `baker.password` but database column is `password_hash`

```javascript
// WRONG (line 3235):
const isValidPassword = await bcrypt.compare(password, baker.password);

// SHOULD BE:
const isValidPassword = await bcrypt.compare(password, baker.passwordHash);
```

**API Error:**
```
POST /api/baker/login → 500 Internal Server Error
{
  "success": false,
  "message": "Internal server error"
}
```

**Console Error:**
```
Baker login error: Error: Illegal arguments: string, undefined
    at Object.compare (bcryptjs/index.js:279:12)
    at routes.ts:3235:44
```

**Root Cause:** `getBakerByEmail()` returns database record with `password_hash` column, but code accesses non-existent `password` property (undefined).

---

### 2. 🔴 **CRITICAL: Demo User Has No Password**
**File:** Database - `bakers` table  
**Issue:** `baker-demo-1` record has `password_hash = NULL`

**Database Query:**
```sql
SELECT id, email, password_hash IS NOT NULL as has_password 
FROM bakers 
WHERE email = 'demo@bakeriq.app';

-- Result:
-- id: baker-demo-1
-- email: demo@bakeriq.app  
-- has_password: false  (NULL)
```

**Comparison:** User record in `users` table DOES have password_hash set:
```sql
SELECT id, email, password_hash IS NOT NULL as has_password 
FROM users 
WHERE email = 'demo@bakeriq.app';

-- Result:
-- id: user-demo-1
-- has_password: true  (HAS HASH)
```

**Root Cause:** Inconsistent data - user created in `users` table but corresponding baker record never got password synced.
