AI Lab Context & Lead→Quote Bridge

Repo: apps/app (BakerIQ).
Goal: Make AI actions deterministic (never arbitrary) by requiring explicit context. Add:

A context panel in AI Lab with Select Quote, Select Lead, and an optional Brief.

Buttons disabled until a quote is selected (from dropdown).

Ability to pick a lead who used the calculator (or any lead), and create a draft quote from that lead in one click.

Backend endpoints accept {quoteId, leadId?, brief?}; if only leadId is provided (no quote yet), create a draft quote and use it.

A) Server: AI endpoints accept context (quote or lead)

In apps/app/server/routes.ts (or wherever AI routes live), update three endpoints:

// helpers
async function ensureQuoteForLead(db, tenantId: string, leadId: string) {
  // find or create a draft quote associated with this lead's customer
  const [lead] = await db.select().from(leads).where(and(eq(leads.id, leadId), eq(leads.tenantId, tenantId)));
  if (!lead) throw new Error('lead_not_found');

  // find or create customer
  let [customer] = await db.select().from(customers).where(and(eq(customers.email, lead.email), eq(customers.tenantId, tenantId)));
  if (!customer) {
    const id = crypto.randomUUID();
    await db.insert(customers).values({ id, tenantId, name: lead.name ?? lead.email, email: lead.email });
    [customer] = await db.select().from(customers).where(eq(customers.id, id));
  }

  // find existing draft quote linked to this customer (optional) or create new
  const [existingQuote] = await db.select().from(quotes).where(and(eq(quotes.tenantId, tenantId), eq(quotes.customerId, customer.id), eq(quotes.status, 'draft'))).limit(1);
  if (existingQuote) return existingQuote.id;

  const quoteId = crypto.randomUUID();
  await db.insert(quotes).values({ id: quoteId, tenantId, customerId: customer.id, title: `Draft for ${lead.name ?? lead.email}`, status: 'draft', total: 0, createdAt: new Date() });
  return quoteId;
}

B) Client: AI Lab Context Panel (Select Quote + Select Lead + Brief)

In apps/app/client/src/pages/ai/AILab.tsx (or your AI Lab page):

Controls at the top:

Select Quote (required): a searchable dropdown fed by GET /api/quotes?status=draft|sent|approved.

Select Lead (optional): searchable dropdown from GET /api/leads?hasCalculator=true (fallback to all leads if you don’t filter yet).

Brief (optional textarea): small free-text to guide suggestions (party size, flavors, theme).

Enable/disable rules:

All three AI action buttons are disabled until a Quote is selected or a Lead is selected (because server will create a draft quote for a lead).

When both are chosen, pass both (server will prefer explicit quoteId).

async function run(path:string, body:any){
  const r = await fetch(path, { method:'POST', headers:{'Content-Type':'application/json'}, body: JSON.stringify(body) });
  const j = await r.json();
  if (!r.ok) throw new Error(j?.error || 'request_failed');
  return j;
}

Buttons are disabled until at least a quote or a lead is chosen.

Summarize Quote and Generate Contract Draft also accept either quote or lead and return useful outputs.

No arbitrary behavior; every AI action clearly shows which quote it’s operating on.
