In apps/app implement a tenant-scoped Auto-Reply system that can send message replies based on templates and rules (e.g., new lead received, after-hours, no response within X hours). Provide API endpoints, admin UI for rules/templates, safe send stubs, and a toggle per tenant.

0) Feature flags

Client .env:

VITE_AUTO_REPLY_ENABLED=true


Server .env / secrets:

AUTO_REPLY_ENABLED=true


(If email/SMS providers are not configured, we’ll keep senders as stubs that log to server and return {ok:true}.)

1) Database (Drizzle)

In shared/schema.ts add:

auto_reply_settings

tenant_id uuid pk, enabled boolean default true,
timezone text default 'America/Chicago',
quiet_hours jsonb (e.g., { from:'21:00', to:'07:00' }),
channels jsonb (e.g., { email:true, sms:false })

auto_reply_templates

id uuid pk, tenant_id uuid, name text, channel text('email'|'sms'),
subject text null, body text, variables jsonb (e.g., ['customer_name','event_date','quote_link']),
created_at, updated_at

auto_reply_rules

id uuid pk, tenant_id uuid, name text, trigger text('new_lead'|'after_hours'|'no_response'),
template_id uuid references auto_reply_templates(id),
conditions jsonb (e.g., { minBudget: 200, sources:['website','instagram'], hoursSinceLastMsg: 12 }),
active boolean default true,
created_at, updated_at

auto_reply_logs

id uuid pk, tenant_id, lead_id uuid null, channel text,
template_id uuid, rule_id uuid,
to_address text, status text('sent'|'skipped'|'failed'),
meta jsonb, created_at default now()
