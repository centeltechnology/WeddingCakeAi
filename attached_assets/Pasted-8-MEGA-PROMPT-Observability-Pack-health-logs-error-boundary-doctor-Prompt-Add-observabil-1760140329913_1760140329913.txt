10) MEGA PROMPT — Importer Pack (CSV → validate → import)

Prompt:
Create CSV importers for Customers, Leads, and Catalog Items.

Goals

Server:

Endpoints: POST /api/import/customers, /leads, /items (multipart CSV).

Parse CSV → dry-run → respond with preview (detected columns, row count, validation errors).

With ?commit=1, insert valid rows; return counts + error CSV for rejects.

Client:

Admin pages (Settings → Import) with upload, preview grid, and Import button.

Validation:

Email/phone normalization for customers/leads; price/qty for items.

Acceptance

Upload CSV shows preview; committing inserts records; user can download error CSV if any.
